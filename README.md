## 一、项目简介

做一个「校园失物招领」页面：用户可以发布**寻物**信息和**招领**信息，集中浏览校园里的失物招领内容，并通过物品名称等关键词搜索；可以查看物品详细信息与发布者联系方式；物品找回或归还后，由**发布者本人**将信息标记为「已找到」或「已归还」。

核心流程：**发布信息 → 浏览 / 搜索 → 查看详情 → 联系发布者 → 更新状态**。

本次**不**实现：复杂后台管理、实名认证、即时聊天、地图定位、消息推送。

## 二、技术选型

**WEB**——移动优先的响应式页面，纯静态 `HTML + CSS + JavaScript`，不依赖构建工具、不依赖后端服务，数据保存在浏览器 `localStorage` 中。

选择理由：助教下载仓库后**直接用 Chrome 打开 `index.html` 就能运行**，无需安装任何环境。

## 三、目录说明

```
102401231-102401228/
├─ index.html            # 唯一入口，双击即可在浏览器打开
├─ README.md             # 本文件：目录说明 + 使用说明
├─ css/
│  ├─ base.css           # 变量、重置、手机宽度画布
│  └─ components.css     # 卡片、徽章、按钮、表单、骨架屏
├─ js/
│  ├─ model.js           # 纯函数：校验 / 筛选 / 状态流转（单元测试对象）
│  ├─ store.js           # localStorage 读写 + 内置示例数据
│  ├─ router.js          # hash 路由（#/home #/search #/publish #/detail/:id #/mine）
│  ├─ ui-common.js       # 各页面共用的渲染小工具（顶部栏、卡片、空状态、提示）
│  ├─ ui-home.js         # 首页
│  ├─ ui-search.js       # 搜索页
│  ├─ ui-detail.js       # 信息详情页
│  ├─ ui-publish.js      # 发布页
│  ├─ ui-mine.js         # 我的发布
│  └─ app.js             # 启动入口：注册路由、同步底部导航、统一接管 data-nav 点击
├─ img/                  # 物品图片素材
└─ tests/                # 单元测试（按作业说明不上传，已在 .gitignore 中忽略）
```

页面路由：`#/home`、`#/search`、`#/publish`、`#/detail/:id`、`#/mine`

> 全部使用普通 `<script>` 标签而不是 ES Module：助教是直接双击 `index.html`
> 用 `file://` 打开的，ES Module 会被同源策略拦下。加载顺序也不能改：
> `model → store → router → ui-common → ui-* → app`。

## 四、使用说明

1. 下载或克隆本仓库到本地。
2. 用 **Chrome 浏览器**双击打开根目录的 `index.html`。
3. 无需安装依赖、无需启动本地服务器、无需联网。

> 建议统一使用谷歌浏览器，避免不同浏览器下页面效果不一致。

## 五、功能清单

| 页面 | 功能 |
| --- | --- |
| 首页 | 搜索入口、全部 / 寻物 / 招领 分类、类别筛选、进行中 / 已结束 切换、信息卡片列表（含加载中 / 加载失败 / 空状态） |
| 搜索 | 关键词搜索（匹配名称、描述、地点）、只看寻物 / 只看招领、热门搜索、无结果空状态 |

| 发布 | 寻物 / 招领切换、表单校验、防重复提交 |
| 我的发布 | 标记已找到 / 已归还、二次确认、撤销标记、编辑 |

## 六、走查用的开关

加载失败、重试这类状态平时不容易复现，所以留了一个演示开关：
在地址栏的路由后面加 `?fail=1`，本次读取就会被强制判定为失败。

| 想看的界面 | 地址 |
| --- | --- |
| 首页加载失败 | `index.html#/home?fail=1` |
| 搜索结果加载失败 | `index.html#/search?kw=雨伞&fail=1` |

点界面上的「重新加载」按钮即可恢复成正常数据。
